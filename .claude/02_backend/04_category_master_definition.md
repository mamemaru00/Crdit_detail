# カテゴリマスタ定義書

## 概要
スプレッドシートの列番号とカテゴリ名の対応を定義するマスタテーブル。システム全体で共通利用。

## データ構造

| 列番号 | カテゴリ名 | 用途 | 備考 |
|--------|-----------|------|------|
| A | 空欄 | システム予約列 | 常に空欄 |
| B | 月 | 月表示 | 1月～12月 |
| C | 食材費 | スーパー、食料品等 | - |
| D | 外食費 | 飲食店、宅配等 | - |
| E | 自己投資費 | 学習、資格等 | - |
| F | 書籍代 | 本、雑誌等 | - |
| G | 家電 | 電化製品等 | - |
| H | 雑貨費 | 日用雑貨等 | - |
| I | 衣服・化粧費 | 衣類、化粧品等 | - |
| J | 娯楽 | 遊び、レジャー等 | - |
| K | 旅行費 | 宿泊、交通等 | - |
| L | - | 未使用 | - |
| M | - | 未使用 | - |
| N | - | 未使用 | - |
| O | 通信費 | スマホ、ネット等 | - |
| P | - | 未使用 | - |
| Q | - | 未使用 | - |
| R | 個人娯楽 | 個人的な趣味等 | - |
| S | - | 未使用 | - |
| T | サブスク | 定期購読サービス等 | - |
| U～V | その他 | カスタムカテゴリ | 拡張用（2列分） |

## 定義ルール

### 未登録店舗の処理
- マッピング未登録の店舗はユーザー確認画面で手動設定
- デフォルト列は設定しない（ユーザーが明示的に選択）

### 列番号範囲
- **予約列**: A列（空欄）、B列（月表示）
- **カテゴリ列**: C～V（20列）
- **拡張可能列**: L, M, N, P, Q, S, U, V（未使用列）

### カテゴリ命名規則
- 最大10文字以内を推奨
- 用途が明確な名称を使用
- スプレッドシートのヘッダー行（行3）と一致

## スプレッドシート連携

### セル更新時の列指定
```python
# 列番号から列インデックスを計算
column_index = ord(column) - ord('A') + 1
# 例: 'C' → 3, 'N' → 14
```

### 行番号計算
```python
# 月データの行番号
row = 3 + month  # ヘッダー3行 + 月番号
# 例: 8月 → 行11
```

## 管理方法
- コード内で定数として定義
- 将来的にデータベース化も検討
- スプレッドシート構造変更時は要同期
