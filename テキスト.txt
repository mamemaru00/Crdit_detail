# ChatGPT分類フロー実装計画

## 0. 先に行うこと（必須）
- **`.claude` 配下の設計書を更新することを最優先で実施する。**
  - 例：
    - `.claude/02_backend/03_mapping_table_definition.md`：SQLiteマッピングテーブル定義の追加
    - `.claude/02_backend/00_backend_architecture.md`：ChatGPT分類フローの追加
    - `.claude/01_development_docs/03_data_flow.md`：CSV → GPT分類 → DB登録 → Sheets反映の追加

## 1. 目的と方針
- **目的**: 未登録店舗をChatGPTで自動分類し、その結果をSQLiteに登録して次回以降の自動分類に利用する。
- **方針**:
  - 既存の「マッピングデータによるカテゴリ判定」を活かす
  - ChatGPTの分類結果を **マッピングとして保存** し、以後は従来の判定ロジックで処理する
  - 既存フロー（CSV → カテゴリ判定 → Sheets更新）を壊さずに前段拡張する

## 2. 追加・変更する機能

### 2.1 ChatGPT分類の前処理
- CSV内の店舗名から「未登録店舗」を抽出
- ユニークな店舗名のみGPT送信対象にする（コスト削減）

### 2.2 ChatGPT API 呼び出し
- 送信内容: `store`（店舗名）中心の一覧
- 返却形式: JSON配列
  ```json
  [
    {"store": "スターバックス", "category": "外食費", "column": "D"}
  ]
  ```

### 2.3 ユーザー確認・手修正フロー（必須）
- ChatGPT分類結果を **ユーザーに一覧で提示** し、必要に応じて手修正できるようにする
- 変更点は **未確定の下書きデータ** として保持し、確定操作後に保存する
- 例: 「確認画面で編集 → 確定ボタン → DB登録」の流れ

### 2.4 SQLite 登録（マッピング保存）
- ユーザーが確定した内容のみ SQLiteの `store_mappings` に保存
- `source=auto` / `priority=4` などで手動優先を担保

### 2.5 マッピング読み込みの差し替え
- `load_mapping_data` を SQLite 読み込みに変更
- `determine_category` / `determine_categories_batch` は流用

## 3. 具体的な実装タスク

### 3.1 設計書更新（先に実施）
- `.claude` 配下の設計書を修正
  - SQLiteテーブル仕様
  - ChatGPT分類フロー
  - 既存のカテゴリ判定フローとの接続点

### 3.2 DB スキーマ作成
- `store_mappings` テーブル
- `unregistered_stores` テーブル（任意）

### 3.3 GPT分類モジュールの追加
- `modules/gpt_classifier.py` など新規作成
- CSV/店舗名配列 → ChatGPT API → JSON返却

### 3.4 app.py にフロー追加
- CSV処理の途中で **ChatGPT分類 → ユーザー確認 → 確定後にDB登録** を差し込む
- 例：`mapping_data` 読み込み前に追加

### 3.5 マッピング判定・Sheets更新
- 既存処理に乗せる（変更最小）

## 4. エラーハンドリング方針
- GPT API失敗時はデフォルトカテゴリで処理続行
- SQLite書き込み失敗時は分類結果を捨てて処理続行し、最後に失敗内容を報告する

## 5. 受け入れ条件（Doneの定義）
- 未登録店舗がGPTで分類され、**ユーザー確認後に** SQLiteに登録される
- 次回のCSV処理で登録済み店舗が自動分類される
- 既存のスプレッドシート更新処理に影響がない

## 6. ChatGPT 送信フォーマット（リクエスト/レスポンス）

### 6.1 リクエスト（ChatGPTへ送るJSON例）
```json
{
  "mode": "THINK",
  "entries": [
    {"store": "スターバックス", "amount": 560},
    {"store": "イオンリテール", "amount": 1234}
  ],
  "categories": {
    "C": "食材費",
    "D": "外食費",
    "E": "自己投資費",
    "F": "書籍代",
    "G": "家電",
    "H": "雑貨費",
    "I": "衣服・化粧費",
    "J": "娯楽",
    "K": "旅行費",
    "O": "通信費",
    "R": "個人娯楽",
    "T": "サブスク"
  },
  "rules": [
    "出力はJSONのみ",
    "categoryとcolumnを必ず返す",
    "分類不能は発生させず、すべて雑貨費（H列）に分類する"
  ]
}
```

### 6.2 リクエスト時の必須プロンプト文
以下のプロンプト文を必ず付与する（役割と出力形式の固定化）。

```
あなたは家計簿分類アシスタントです。
以下のCSV明細に対して、指定された列カテゴリに分類してください。
理由は返さず、JSONのみ返してください。
```

### 6.3 レスポンス（ChatGPTから返るJSON例）
```json
[
  {"store": "スターバックス", "category": "外食費", "column": "D"},
  {"store": "イオンリテール", "category": "食材費", "column": "C"}
]
```
